# Find out fake friend on X

一个在 X 网页上使用的 Chrome 扩展。读取当前账号的关注列表，由你选择要清理的账号，再逐个执行取关。

扩展可直接安装，无需构建、启动服务或安装 npm 依赖。

[下载插件 ZIP](https://github.com/stevenchenUCD/Find-out-fake-friend-on-X/releases/latest/download/fake-friend.zip) · [使用说明](使用说明.md)

## 功能

- 扫描自己的“正在关注”列表，查看当前未回关的账号。
- 支持白名单、跳过列表前 N 人，以及在名单中直接选择账号。
- 按你确认的名单分批取关，支持暂停、继续和停止。
- 按登录账号分别保存白名单、设置和操作记录，支持导出备份和导入白名单。
- 可拖动面板底部调整高度，并记住当前账号上次使用的尺寸。
- 提供 20 种界面语言，语言资源随扩展加载。

“未回关”表示你当前关注对方、对方当前没有关注你。插件不判断过去是否互关。

## 安装

需要 Chrome 120 或更高版本，并在浏览器中登录 X。

1. 点击 [下载插件 ZIP](https://github.com/stevenchenUCD/Find-out-fake-friend-on-X/releases/latest/download/fake-friend.zip)，下载并解压安装包。
2. 打开 Chrome 的 `chrome://extensions` 页面。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的 **`extension` 文件夹**。该文件夹内应直接包含 `manifest.json`。
5. 将 **Fake Friend** 固定到浏览器工具栏。
6. 点击插件图标，再点“前往我的关注列表”。

请保留安装时选中的文件夹。更新文件后，在扩展管理页点击重新加载，再刷新 X 页面。

## 使用

1. 设置白名单和跳过范围。
2. 点击“扫描关注列表”。
3. 在“本轮名单”中选择“跳过”“白名单”或“假朋友”。“假朋友”表示你已选中该账号，准备取关。
4. 扫描暂停、停止或结束后，点击“开始执行”，处理当前已选中且尚未处理的账号。
5. 查看结果，需要时通过“备份与恢复”导出记录。

只有核实同一账号的按钮变为“关注”，才记为成功。结果未确认时需要人工核对，插件不会自动重试取关。隐藏面板会暂停任务；刷新或关闭网页后需要重新扫描。完整的暂停、恢复和异常处理规则见 [使用说明](使用说明.md)。

## 数据与使用范围

- 白名单、设置和操作记录保存在当前浏览器的 `chrome.storage.local` 中，并按登录账号分别保存。
- 插件使用 X 网页已有的登录状态，无需填写密码、Cookie 或 API 密钥。
- 一次在一个 X 标签页运行。扫描范围取决于 X 当前展示的列表，无法保证网页提供了完整关注数据。
- X 页面变化可能影响识别和操作。平台使用限制与已知边界见 [使用说明](使用说明.md)。

## 开发与验证

开发验证可使用 Node.js 24 和 npm。锁定依赖也支持 Node.js 20.19+（20.x）或 22.12+（22.x）。安装和运行扩展本身不需要 Node.js。

在项目根目录（包含 `package.json` 的目录）打开终端，执行：

```sh
npm ci
npm run check
npm test
```

`npm run check` 检查扩展清单、文件引用、权限和 JavaScript 语法；`npm test` 运行本地自动化测试。

需要查看模拟页面时，可单独运行：

```sh
npm run preview
```

终端会输出本地页面地址。模拟页使用虚构账号，与真实 X 无连接；按 `Ctrl+C` 停止预览。本地测试和模拟页不代表真实 X 页面上的验证。

## 项目结构

| 路径 | 用途 |
|---|---|
| `extension/` | 可直接安装的完整扩展 |
| `extension/manifest.json` | Chrome 扩展入口和权限声明 |
| `extension/src/localization/` | 本地语言资源 |
| `tests/` | 自动化测试与本地模拟页面 |
| `scripts/check.mjs` | 开发静态检查 |
| `package.json`、`package-lock.json` | 开发命令和锁定依赖 |
| [使用说明.md](使用说明.md) | 详细安装、操作与行为说明 |

`node_modules/` 和 `temp/` 已通过 `.gitignore` 排除。发布供安装的 ZIP 时，包含完整的 `extension/` 文件夹和根目录的 `LICENSE`；用户解压后加载 `extension/` 即可。
